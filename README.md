# Terep 30

Böngészős low-poly autós fizikajáték éjszakai pályán. A Terep2 (Nagymáthé Dénes, 1994–1996) inspirálta.

Játék: nyisd meg az `index.html`-t, vagy a GitHub Pages linket.

Irányítás: W/A/S/D vagy nyilak, Space kézifék, Shift boost, E ugrás/lebegés, Q szívás, R visszaállítás, C kamera, F1 súgó. Gamepad is működik, egérrel körbe lehet nézni.
